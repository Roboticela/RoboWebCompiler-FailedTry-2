CSS Conformance

One document and one stylesheet holding every CSS property and every value this compiler implements. Each demo below is the declaration its caption names, so the page is the list of what works, and CssPipeline.TheConformanceExampleCompilesWithoutADiagnostic keeps it honest: a value that stops compiling fails the suite.

1. Custom properties and var()

A custom property is substituted before the value is parsed: it can stand in for a whole value, an operand of a function, or a fallback, and it inherits.

17. The CSS-wide keywords

all: initial — every property goes back to its initial value

all: inherit — every property takes the parent's computed value

all: unset — inherited properties inherit, the rest go back to initial

Reported rather than implemented

These are named so the sheet stays a list of what works. Each is reported by the compiler with its reason and does not change the document:

  • display: grid, table, contents, flow-root, list-item — the native layout engine has block, inline, inline-block, flex and none.
  • margin: auto — the native layout engine does not distribute free space.
  • background-color: currentcolor without an explicit color — there is no native colour to borrow. With a color set it resolves to it, as in section 6.
  • border-radius with more than one value, or the elliptical / form — the native radius is one circular length. The four corner longhands are accepted and the single value paints every corner.
  • stretch, fit-content(<length>) and anchor-size() on the size properties — a length, a percentage, auto, none and min-content/max-content/fit-content are implemented, these three need an intrinsic-size pass or an anchor to measure against.
  • percentages in margin, padding, border-width and font-size — the native box holds resolved lengths; they are supported in width, height and min-*.
  • text-align: match-parent — there is no parent writing mode to inherit one from.
  • text-transform: full-width, full-size-kana, math-auto — the case transforms are implemented, these are not.
  • text-indent: each-line, hanging — the indent itself is implemented.
  • text-decoration-line: spelling-error, grammar-error — underline, overline, line-through and blink are.
  • font-size: math, and the font shorthand's family, line-height, weight, style and variant halves.
  • flex — the shorthand over flex-grow, flex-shrink and flex-basis is carried, not expanded into the three longhands. The rest of the flex model, wrapping and gaps included, is implemented above.
  • z-index is compiled and accepted, and does not yet reorder painting.
  • sticky takes its offsets like a relative box; the scrollport clamp is not modelled.
  • env(), attr(), counter(), counters(), anchor(), anchor-size(), calc-size(), element(), if(), progress(), random(), sibling-index(), sibling-count() and the image and grid functions — the numeric functions and var() are implemented, these need a document or a runtime.
  • grid, transforms, transitions, animations, filters, gradients, background images, custom fonts, logical properties, container queries — carried, not compiled: accepted and kept, never drawn.
