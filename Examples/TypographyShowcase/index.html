Typography Showcase

One document, every writing system. The runtime resolves each code point through Inter and then a fallback chain, shapes the run with the face's own OpenType Layout, breaks real text, and paints filled glyph outlines and colour glyphs it rasterizes itself.

Default family: Inter · Shaping: GSUB/GPOS · Colour: COLR/CPAL and CBDT · Fallbacks: system faces

Long text: line breaking

Pack my box with five dozen liquor jugs, then watch the runtime measure every glyph, find the real break opportunities, and lay the result into line boxes. Because the advances come from the font rather than from a table of fixed widths, a wide letter and a narrow one occupy the room they actually need, and bold occupies more room than regular. Words that are too long for the measure break inside the word rather than overflowing the container, and whitespace is never counted at the end of a line.

在中文里，换行可以发生在任意两个汉字之间，也可以发生在标点符号之后。 渲染器在测量每一个字形之后，会在合适的位置断开这些长行，从而让整段文字 填满可用的宽度，而不会溢出容器。混合 English words 与中文汉字时，两种 断行规则应当同时生效。
