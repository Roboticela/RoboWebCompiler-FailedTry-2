Variable names must be camelCase and descriptive. Avoid using generic names like "data" or "temp". Use clear and meaningful names that convey the purpose of the variable.

Function names must be PascalCase and descriptive. Avoid using generic names like "process" or "handle". Use clear and meaningful names that convey the purpose of the function.

File and Folder names must be PascalCase and descriptive. Avoid using generic names like "files" or "temp". Use clear and meaningful names that convey the purpose of the file or folder.
